# Client Payment QR Request Portal

Standalone client-facing application for requesting Payment QR codes and submitting payment UTR reference numbers.

## Features
- Mobile number & amount request form
- Real-time live status waiting screen
- Auto-displays QR code sent by Admin
- Mobile UPI launcher buttons (GPay, PhonePe, Paytm, BHIM)
- Payment UTR submission with screenshot upload

## Run
```bash
npm install
node server.js
```
Open `http://localhost:3000`
